# StudyPilot

StudyPilot is an AI-powered student productivity and learning platform.

## Features Built So Far:
- **Phase 1**: PostgreSQL Database & Prisma ORM, Models (User, Course, Assignment, Task)
- **Phase 2**: JWT Authentication, Role-Based Access Control, Security (Helmet, Rate Limiting)
- **Phase 3A**: Centralized AI Foundation with Google Gemini, prompt engineering, mocked tests, and structured outputs.
